# AtliQ-Hardware-Business-Insights-360-Power-BI
Power BI business intelligence project analyzing Finance, Sales, Marketing, Supply Chain, and Executive performance.
## 📌 Project Overview

AtliQ Hardware Business Insights 360 is a business intelligence project developed to analyze business performance across multiple departments. The project uses interactive Power BI dashboards to help stakeholders understand business trends, monitor key performance indicators (KPIs), and make data-driven decisions.

## 🎯 Project Objectives

- Analyze business performance across Finance, Sales, Marketing, and Supply Chain.
- Develop interactive dashboards to monitor key performance indicators.
- Understand sales trends, profitability, and customer performance.
- Evaluate forecast accuracy and supply chain performance.
- Provide meaningful insights to support business decision-making.

## 📊 Dashboard Views

### 1. Finance View
- Analyze financial performance and profitability.
- Monitor key financial metrics and trends.
- Evaluate business performance using financial indicators.

### 2. Sales View
- Analyze customer and product performance.
- Understand sales trends and performance.
- Identify areas for sales improvement.

### 3. Marketing View
- Analyze product and market performance.
- Monitor marketing-related business metrics.
- Understand profitability and performance trends.

### 4. Supply Chain View
- Analyze forecast accuracy and supply chain performance.
- Monitor forecast-related metrics.
- Identify areas for operational improvement.

### 5. Executive View
- Provide an overview of overall business performance.
- Monitor key business metrics across departments.
- Support strategic decision-making.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| MySQL | Data querying and retrieval |
| Microsoft Excel | Data analysis and validation |
| Power BI Desktop | Interactive dashboard development |
| Power Query | Data cleaning and transformation |
| DAX | Measures, calculations, and business logic |
| DAX Studio | DAX analysis and performance optimization |
| Power BI Service | Report publishing and sharing |

## 💡 Key Technical Learnings

- **Data Modeling:** Understanding table relationships and data models.
- **DAX:** Using functions such as CALCULATE, FILTER, ALL, DIVIDE, IF, SWITCH, and SELECTEDVALUE.
- **Time Intelligence:** Analyzing business performance over time.
- **Dashboard Design:** Creating interactive reports with slicers, filters, bookmarks, and page navigation.
- **Data Visualization:** Presenting business metrics using charts, cards, and KPIs.
- **Performance Optimization:** Understanding DAX Studio and report performance.
- **Data Validation:** Checking report calculations and data accuracy.
